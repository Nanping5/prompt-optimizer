# Prompt Optimizer v2.16.0

## Summary

This minor release redesigns the shared workspace around a calm macOS-inspired light theme, consolidates navigation, strengthens the prompt and test workflow hierarchy, and unifies the application icon across Web, PWA, Desktop and the browser extension.

## Highlights

- Use a light canvas, white cards, restrained indigo accents and softer elevation across the application.
- Navigate function and sub-mode choices through one integrated header rail instead of separate wrapping groups.
- Follow a clearer left-side prompt workflow and right-side test/preview/result hierarchy.
- Use the LobeHub Clerk icon as a consistent application mark on every release surface.
- Keep dark mode, reduced motion, reduced transparency and higher contrast support.

## Product Updates

### Desktop

- Package the redesigned shared workspace for macOS Intel, macOS Apple Silicon and Windows x64.
- Apply the new application icon to native desktop artifacts and automatic-update metadata.

### Web

- Apply the refreshed workspace theme, consolidated navigation, card hierarchy, empty states and responsive layouts.
- Update browser, PWA and Apple touch icons to the new Clerk-based mark.

### Extension

- Apply the shared visual and navigation improvements.
- Replace the extension action icons and favicon with the new application mark.

### Core/Infra

- Keep business services, storage, sessions and model integrations unchanged.
- Add a dedicated GitHub Actions release workflow for macOS and Windows x64 desktop artifacts.

## Fixes

- Prevent the mode and sub-mode navigation from wrapping into two rows at intermediate desktop widths.
- Keep the workspace utility controls inside the central divider instead of leaving a detached column at the viewport edge.
- Use Lucide icons for compact header configuration actions.

## Breaking Changes / Upgrade Notes

- No breaking API, storage-format or session migration is required.
- Desktop builds are unsigned unless repository signing secrets are configured; users may need to confirm the operating-system warning on first launch.

## Developer Notes

- Verify 1440px, 1280px, 1024px, 768px and 375px layouts, light and dark themes, compact test navigation and zero horizontal document overflow.
- UI type checking, UI/Web production builds, ESLint, locale checks and 44 focused component tests pass.
- The private release workflow builds only macOS and Windows x64 artifacts and publishes them to the tagged GitHub Release.
