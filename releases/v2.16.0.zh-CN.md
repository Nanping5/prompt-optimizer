# Prompt Optimizer v2.16.0

## 概括

本次小版本以克制的 macOS 浅色视觉重构共享工作区，合并顶部导航，强化提示词与测试流程的信息层级，并统一 Web、PWA、桌面端和浏览器扩展的应用图标。

## 亮点

- 使用浅色画布、白色卡片、低饱和靛蓝强调色和更柔和的层次阴影。
- 将功能模式和子模式整合到同一条顶部导航轨道，避免中等宽度下拆成两行。
- 左侧建立“原始提示词 → 模型与策略 → 优化结果”的清晰流程，右侧分层组织测试素材、配置、预览和结果。
- 使用 LobeHub Clerk 图标作为所有发布界面的统一应用标识。
- 继续支持深色主题、减少动效、减少透明度及高对比度设置。

## 产品更新

### Desktop

- 为 macOS Intel、macOS Apple Silicon 和 Windows x64 打包重构后的共享工作区。
- 将新的应用图标应用到原生桌面产物和自动更新元数据。

### Web

- 应用新的工作区主题、整合导航、卡片层级、空状态和响应式布局。
- 更新浏览器、PWA 和 Apple Touch 图标。

### Extension

- 应用共享视觉和导航改进。
- 将扩展工具栏图标及 favicon 替换为新的应用标识。

### Core/Infra

- 保持业务服务、存储、会话和模型集成不变。
- 新增仅构建 macOS 与 Windows x64 桌面产物的 GitHub Actions 发布流程。

## 修复

- 修复中等桌面宽度下功能和子模式导航拆成两行的问题。
- 将工作区工具入口收进中央分隔区域，移除视口右缘的独立浮动列。
- 为紧凑的顶部配置操作统一使用 Lucide 图标。

## 破坏性变更 / 升级说明

- 无破坏性 API、存储格式或会话迁移。
- 若仓库未配置签名密钥，桌面构建将保持未签名，首次打开时可能需要用户确认系统安全提示。

## 开发者说明

- 已验证 1440px、1280px、1024px、768px 和 375px 布局、明暗主题、移动端测试导航，并确认页面无横向溢出。
- UI 类型检查、UI/Web 生产构建、ESLint、Locale 检查及相关组件测试 44 项全部通过。
- 私有仓库发布流程只构建 macOS 与 Windows x64 产物，并上传到带标签的 GitHub Release。
